YoWorld Paint v3.5.15

IMPORTANT: Browser extensions are installed separately in each browser profile.
This test must be loaded in the same profile where you use YoWorld.

Installation:

1. Extract this ZIP to its own folder.
2. Open the normal Chromium browser profile where you use YoWorld.
3. Open the browser's Extensions page and turn on Developer mode.
4. Temporarily disable every older YoWorld Paint copy in that profile so there is only one active test copy.
5. Choose Load unpacked and select the extracted v3.5.15 folder.
6. Pin "YoWorld Paint" from the browser's Extensions menu.
7. Close any YoWorld Paint side panel that is already open.
8. Click the test extension's toolbar icon once.

Navigation and permission test:

1. Open the extension from its toolbar icon. Chrome and Edge should use Side Panel; a browser without the Side Panel API should use Popup.
2. Confirm the tabs are Home, Transform, Tools, FAQ, and Resources.
3. Confirm there is no Sales Boards tab.
4. Open the browser's Extensions page, select YoWorld Paint Details, and confirm it does not request access to all websites.

Expected result:

The current Paint Board tools load normally and the removed Sales Boards feature does not request scripting, active-tab, or all-sites access.

Picrd quality and persistence test:

1. In Quick Image Uploader, leave "Game-ready 390×260 (save optimized)" checked.
2. Confirm Host is "Picrd (free, no API key)."
3. Leave "Clean faint transparency" OFF for an image with glow, translucent art, or soft edges.
4. Upload the transparent PNG and keep Auto-set as Current Image checked.
5. Approve Picrd upload access if the browser asks the first time.
6. Confirm the extension preview retains the artwork's colors, gradients, and soft details without severe grain or color shifts.
7. Enable Redirect.
8. Keep Redirect ON while you open the Paint Board and press Save/OK the first time.
9. Wait for the save to finish, then turn Redirect OFF.
10. Open the saved board and press OK.

Expected result:

The prepared Picrd image should be used directly without contacting YoWorld Info or another image relay. Soft details should be preserved when the cleanup checkbox is off. For a separate image with unwanted faint background color, enable Clean faint transparency and confirm the haze is removed. The image should remain after Redirect is turned off following the first completed save. ImgBB should still remain selectable in the Host menu.

Adaptive quality test:

1. Upload a simple graphic or Sales Board with Game-ready mode enabled.
2. Confirm its important colors remain close to the original.
3. Upload a detailed photograph or room image.
4. Confirm the result remains recognizable and reasonably smooth, then complete the Redirect ON/OFF save workflow.

Expected result:

The extension should preserve exact full-color PNG data when it fits the save target and use the highest-quality perceptual palette that fits when compression is required. Both examples should remain saved after Redirect is turned off.

Default-view test:

1. Open Resources, the last tab.
2. Under Default View, select Popup.
3. Close the side panel and click the toolbar icon. The popup should open.
4. In Chrome or Edge, open Resources and select Side Panel (recommended).
5. The side panel should open, and future toolbar clicks should use it.
6. In Opera, Opera GX, Brave, or Vivaldi without Side Panel support, confirm the Side Panel option is disabled and the popup continues to open.

Cross-browser fallback test:

1. Install the same unpacked build in each available current desktop browser: Chrome, Edge, Opera or Opera GX, Brave, and Vivaldi.
2. Click the toolbar icon and confirm the full Home interface opens rather than a blank panel or an unresponsive icon.
3. Change the theme and uploader host, close the interface, reopen it, and confirm the choices were saved.
4. Upload a test image to Picrd, turn Redirect on, and confirm the Paint Board receives the image.
5. Complete the normal first-save workflow, turn Redirect off, reopen the board, and confirm the image remains saved.

Expected result:

Browsers with Chrome's Side Panel API may use Side Panel. All other supported Chromium browsers must automatically use the Popup. Settings may use synchronized storage when the browser provides it or local extension storage otherwise. No browser-specific permission should be added.
