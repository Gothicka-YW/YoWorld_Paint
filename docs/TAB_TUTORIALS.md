# YoWorld Paint Tab Tutorials

These notes describe the active v3.5 tabs.

## Home

Goal: upload or set the image that will be applied to YoWorld paint boards.

Steps:

1. Paste a direct image URL, or use Quick Image Uploader.
2. Turn on Transparency Mode for direct transparent PNGs.
3. Turn on Enable Redirect.
4. In YoWorld, open the target board and press OK.
5. Turn Redirect off.
6. Reopen the board and press OK again to lock it in.

Tips:

- Multiboard behavior is automatic.
- Direct ImgBB PNGs can receive a hidden save-helper image.
- The Home tab no longer shows Copy Redirect Trace or Clear Trace controls.

## Transform

Goal: pre-warp artwork for angled boards.

Steps:

1. Pick a preset.
2. Upload the source image.
3. Choose resize and multitile settings.
4. Apply.
5. Export the generated tile or tiles.
6. Upload each tile from Home.

## Tools

Goal: calculate board dimensions and split artwork into board-sized tiles.

Steps:

1. Enter board columns and rows in Board Size Calculator.
2. Resize or prepare artwork to the target size.
3. Upload/paste/drop it into Image Splitter.
4. Split and download the tiles.
5. Upload each tile from Home.

## Resources

Goal: settings and links.

Steps:

1. Save or test the ImgBB API key.
2. Select Popup or Side Panel mode.
3. Choose a theme.

## Retired: Sales Boards

The Sales Boards tab and YoWorld Info capture workflow are no longer active. Use Windows crop/snipping plus Home Quick Image Uploader instead.
