***** HOW TO INSTALL THE EXTENSION *****

1. Unpack the YoWorld Paint v3.5.15 ZIP and remember the extracted folder location.

2. Open extension page
Open the Extensions page for your browser:
- Chrome or Brave: chrome://extensions
- Microsoft Edge: edge://extensions
- Opera or Opera GX: opera://extensions
- Vivaldi: vivaldi://extensions
or
Use the menu: ⋮ > More tools > Extensions

3. Enable "Developer mode" in the upper-right corner of the page

4. Select "Load unpacked" option

5. Select the unpacked "YoWorld Paint v3.5.15" folder.

6. Open the folder

7. That's it. You can find the extension on the chrome://extensions page
