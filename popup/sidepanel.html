Quick Image Uploader (recommended)

  1. Open the Home tab.
  2. In Quick Image Uploader: paste, drag & drop, or click to select an image.
  3. Click Upload.
  4. Leave Prepare as 390×260 PNG ON for the most reliable save workflow.
  5. If Prepare is OFF: smaller images are kept fully visible, and larger images are sent to Tools > Image Splitter.
  6. Optional: leave “Auto‑set as Current Image” ON to apply immediately.

Manual direct link

  1. Resize your image to 390×260 (PNG recommended).
  2. Upload it to a host that provides a direct image link (ImgBB, Imgur, etc.).
  3. Copy the direct image link.
  4. In the Home tab, paste the link and click “Set New Image.”

Apply to YoWorld

  1. Turn on Enable Redirect.
  2. In YoWorld, open the paint board and press OK.
  3. Return to YoWorld Paint and turn off Enable Redirect.
  4. Reopen the same paint board and press OK again to lock it in.
  5. For multiple boards, repeat the OK step on each board while Redirect is on. Multiboard support is automatic.

Tips

  • Paste everywhere: You can paste images directly into Home fields.
  • Hosting: ImgBB is integrated and reliable; set your API key in Resources.
  • Transparency: Transparency Mode creates a direct PNG preview and a save-compatible helper when needed.
  • Text readability: If a large collage has tiny text, split it in Tools > Image Splitter instead of squeezing everything into one board.
  • Retired: Sales Boards and YoWorld Info capture have been replaced by crop/snipping plus Quick Image Uploader.
